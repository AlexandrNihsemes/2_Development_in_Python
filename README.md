# Проект 9.1 Masking bank card and account numbers.

## Описание:
9.1 Masking bank card and account numbers - это веб-приложение на Python 
для обработки банковских операций. 

## Модули:
1. masks - маскирует номер карты и номер счёта.
2. widget - маскирует номер карты или номер счёта в зависимости от ввода и
корректирует дату.
3. processing - фильтрует словари по значению и убыванию.
4. generators - принимает список словарей на вход и возвращает итератор,
использует yield для генерации значений по запросу, созжан генератор банковских карт.
5. decorators - зтот модуль используется для размещения декораторов, включая декоратор 
log.
6. utils - возвращает список словарей с данными о финансовых транзакциях из JSON-файла.
7. external_api - возвращает сумму транзакции и конвертации суммы операции в рубли.
8. finance - возвращает списки транзакций из файлов CSV и  Excel.
9. search - для поиска транзакций по заданному слову и подсчета количества операций 
по категориям из списка транзакций.
10. main - объединяет основную логику проекта и связывает функциональности между собой.

## Использование:
1. Для использования модуля "masks" нужно подать в функции номер карты и номер счёта.
2. Для использования модуля "masks" нужно подать в функции номер карты или номер счёта,
а также дату.
3. Для использования модуля "processing" нужно подать в функции словари с данными.
4. Для использования "generators" нужно подать в функции словари с данными,
а также range для генерации номеров карт.
5. Для использования "decorators" принимает необязательный аргумент 
filename, который определяет, куда будут записываться логи (в файл или в консоль).
6. Для использования "utils" принимает на вход путь до JSON-файла.
7. Для использования "external_api" принимает на вход транзакцию, а также происходит
обращение к внешнему API.
8. Для использования "finance" принимает на вход пути к файлам CSV и  Excel.
9. Для использования "search" принимает на вход список транзакций и слово для поиска,
категорию для поиска.
10. Для использования "main" принимает запросы в консоль.
